# Place Moderation

- Route: `/admin/places`.
- Có thống kê, lọc tất cả/chờ duyệt/đã duyệt và card địa điểm có ảnh, rating, vị trí.
- Nút phê duyệt, từ chối và gỡ bỏ cập nhật state thật.
- Desktop dùng grid 3 cột; tablet 2 cột; mobile 1 cột theo thiết kế responsive.
- Build: `npm run build` pass.
- Visual analytics: moderation funnel, phân bổ khu vực và sparkline địa điểm mới.

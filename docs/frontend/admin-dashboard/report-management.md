# Report Management

- Route: `/admin/reports`.
- Hiển thị metric xử lý, tab chờ/đã xử lý/tất cả và danh sách báo cáo theo mức ưu tiên.
- Nút xử lý đóng báo cáo, lưu localStorage và cập nhật số liệu Dashboard.
- Build: `npm run build` pass.
- Visual analytics: xu hướng tốc độ xử lý, donut SLA và biểu đồ mức độ ưu tiên.

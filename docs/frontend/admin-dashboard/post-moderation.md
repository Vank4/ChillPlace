# Post Moderation

- Route: `/admin/posts`.
- Hàng đợi nội dung hỗ trợ lọc trạng thái và hiển thị lý do, độ ưu tiên, tác giả, trích đoạn.
- Các hành động phê duyệt, gỡ bỏ và cảnh cáo đồng bộ với Report Management.
- Mobile giữ ảnh và hành động chính, giảm metadata để tránh tràn.
- Build: `npm run build` pass.
- Visual analytics: donut nguồn phát hiện, heatmap báo cáo theo giờ và risk composition bars.

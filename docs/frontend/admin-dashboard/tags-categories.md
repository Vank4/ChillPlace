# Tags And Categories

- Route: `/admin/tags`.
- Quản lý hashtag và danh mục địa điểm: thêm mới, chống trùng và xóa.
- Dữ liệu được lưu qua `admin.service.js`.
- Desktop hai cột, mobile một cột; hỗ trợ light/dark mode và trạng thái hover/focus.
- Build: `npm run build` pass.
- Visual analytics: hashtag growth bars, heatmap nhịp sử dụng và sparkline lượt khám phá từ thẻ.
